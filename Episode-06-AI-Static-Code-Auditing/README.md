# Episode 06: AI-Powered Static Code Auditing (SAST) for SQLi & XSS 🔍🤖

Welcome to **Episode 6** of the **AI for Cybersecurity: Zero to Hero** series by **Ethical Vyaspeeth**!

In this episode, we build an automated **Static Application Security Testing (SAST)** tool using Python and a local **Ollama LLM**. This tool parses raw source code (PHP, Python, JS, C++) to identify critical security flaws like **SQL Injection (SQLi)** and **Cross-Site Scripting (XSS)** without running the application, and generates secure refactored code patches.

## 🛠️ Key Features
* 🔍 **Automated SAST Parsing:** Audits uncompiled source code files for OWASP Top 10 vulnerabilities.
* 🔒 **100% Private & Offline:** Securely audits proprietary code without sending source files to cloud servers or third-party APIs.
* 🛠️ **Remediation & Refactored Patches:** Generates production-ready fix recommendations (e.g., PHP PDO Prepared Statements, `htmlspecialchars()` sanitization).
* 📝 **Timestamped Markdown Reports:** Automatically saves structured audit reports into `reports/`.

## 🚀 Quick Setup Instructions

### Step 1: Install Dependencies
```bash
pip3 install -r requirements.txt
```
(If on Kali Linux with PEP 668 restriction, use pip3 install ollama --break-system-packages)

### Step 2: Ensure Ollama is Active
```bash
systemctl status ollama
ollama pull llama3
```

### Step 3: Run the SAST Tool
```bash
python3 ai_code_auditor.py sample_code/vulnerable_login.php
```

---

## 💡 Usage Example
1. Run python3 ai_code_auditor.py sample_code/comment_section.php.
2. Inspect terminal output for line-by-line flaw explanations.
3. Review generated report file saved in reports/sast_report_comment_section_php_<timestamp>.md.
